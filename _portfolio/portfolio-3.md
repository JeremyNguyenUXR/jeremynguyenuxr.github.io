## Overview

This is a final project for a webdesign course to develop and demonstrate my design skills learnt through out the semester by making a personal website. My goal was to create a responsive website that's visually appealing, showcases my branding while also meeting WCAG 2.0 accessibility standards. This website and all media within it was developed by me and coded in HTML and CSS using a bootstrap architecture.
